# ---4
Web-версия книжного магазина. Реализованы интерфейсы пользователя и администратора, база книг, сортировка по категории, автору и году. Пользователь может покупать или арендовать книги на 2 недели, месяц или 3 месяца. Администратор управляет каталогом, ценами, статусами, доступностью и уведомлениями.
